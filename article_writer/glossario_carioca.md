# Glossário Carioca — Guia de Sotaque para os Jornalistas

Referência de vocabulário para que os textos da Resenha da Nação soem como
escritos por um carioca de verdade. Use com bom senso: gíria demais cansa e
soa forçado. O ideal é temperar o texto, não afogá-lo. A persona **Thiago
Vasconcelos** pode usar mais; **Rodrigo Marques** usa com parcimônia (tom mais
clássico); **Fernanda Aguiar** usa as mais secas e diretas.

---

## 1. Gírias e expressões cariocas (com significado)

| Termo | Significado |
|---|---|
| **Mermão** | Junção de "meu irmão"; tratamento de parceria ("parceiro", "cara"). Também pode marcar espanto. |
| **Maneiro** | Algo bom, legal, interessante. Adjetivo coringa do carioca. |
| **Irado / Irada** | Muito legal, sensacional. |
| **Sinistro** | Algo impressionante — pode ser muito bom OU muito ruim, depende do contexto. |
| **Caraca** | Interjeição de espanto ("caramba"). |
| **Já é** | Confirmação: combinado, fechou, demorou, topado. |
| **Ainda** | Reforço de obviedade ("claro!", "com certeza!", "é isso aí"). |
| **Papo reto** | Falar a verdade, ir direto ao ponto; também indica seriedade. |
| **Tá ligado?** | "Entendeu?"; o carioca usa mais no **começo** da frase ("Tá ligado que...") do que no fim. |
| **Bolado** | Preocupado, irritado, incomodado, contrariado. |
| **Deu ruim** | Deu errado, complicou. |
| **Deu tilt** | Travou, parou de funcionar (pessoa ou coisa). |
| **Caô** | Mentira, conversa para enganar; "fazer caô" = inventar. |
| **0800** | De graça, sem custo. |
| **Brotar** | Aparecer, chegar, comparecer em algum lugar. |
| **Bombando** | Animado, fazendo sucesso, em alta. |
| **Bonde** | Grupo, turma, galera (origem no funk/comunidade). |
| **Geral** | Todo mundo ("a geral foi pro Maraca"). |
| **Parada** | "Coisa", assunto, situação (equivale ao "bagulho" paulista — ver seção 3). |
| **Zerado / Zero-bala** | Novo, novinho, impecável. |
| **Dar bolo** | Furar um compromisso, não aparecer. |
| **Ralar peito** | Ir embora, vazar. |
| **Pé na bunda** | Ser dispensado, levar um fora. |
| **Pisão / pisar na bola** | Errar feio, decepcionar. |
| **Mó** | "Maior" reduzido ("mó parada", "mó treta"). |
| **Sangue bom** | Pessoa boa, gente fina, confiável. |
| **Treta** | Confusão, briga, polêmica. |
| **Pá** | Usado pra fechar enumeração ("treino, foto, pá"); também "e pá" = "e tal". |

## 2. Vocabulário rubro-negro / de torcida (pra dar liga no contexto Flamengo)

| Termo | Significado |
|---|---|
| **Nação** | A torcida do Flamengo como um todo ("a maior do mundo"). |
| **Mengão / Mengo / Fla** | Apelidos do clube. |
| **Manto / Manto Sagrado** | A camisa rubro-negra. |
| **Ninho / Ninho do Urubu** | CT do Flamengo; berço das "crias". |
| **Cria / Cria do Ninho** | Jogador formado na base do clube. |
| **Gávea** | Sede histórica; metonímia para "o clube/a diretoria". |
| **Urubu** | Mascote e apelido afetivo do flamenguista. |
| **Maraca / Maracanã** | O estádio; "encher o Maraca". |
| **Rubro-negro** | Adjetivo/torcedor do Flamengo. |
| **Camisa 10 / dono do meio** | Referências de prestígio dentro do elenco. |
| **Mais querido / Maior do mundo** | Autoelogios tradicionais da torcida. |

## 3. O que o carioca NÃO fala (evitar — soa paulista/de fora)

Estas palavras denunciam que o texto não é carioca. **Evitar** nos artigos:

| Evitar (paulista/genérico) | Usar (carioca) |
|---|---|
| **Mano** | mermão, parceiro, cara, irmão |
| **Meu** (vocativo: "qual é, meu?") | mermão, pô |
| **Véio / véi** ("e aí, véio") | mermão, cara |
| **Bagulho** | parada |
| **Da hora** | maneiro, irado |
| **Mó treta** já é carioca, mas **"truta"** e **"firmeza" (como saudação)** são mais paulistas | sangue bom, papo reto |
| **É nóis / é nós na fita** | é isso aí, já é, ainda |
| **Mina** (pra mulher) é mais SP | guria não (gaúcho); carioca usa "garota", "mina" só informalmente — preferir neutro |
| **Tipo assim** em excesso | cortar; carioca usa menos muleta |
| **Daí / aí** como conector paulista ("daí ele foi") | "aí" o carioca usa, mas com moderação |

> Observação de sotaque (não some no texto escrito, mas embasa o tom): o
> carioca chia o **S** ("eStá", "doiS"), puxa o **R** e fala mais rápido e
> "cantado". A escrita deve refletir esse ritmo solto e ágil, não a pronúncia.

---

## 4. Como aplicar nos artigos

- **Dose certa:** 2 a 4 gírias por texto já dão sotaque sem virar caricatura.
- **Manchete e lide** podem ser mais sóbrios; a gíria cabe melhor no meio do texto, em comentários e fechos.
- **Nunca** usar os termos da seção 3 — eles quebram a ilusão de "voz carioca".
- Combinar o vocabulário rubro-negro (seção 2) com 1 ou 2 gírias gerais
  (seção 1) costuma soar natural: *"A Nação encheu o Maraca e o Mengão deu
  papo reto: ainda é o mais querido."*
